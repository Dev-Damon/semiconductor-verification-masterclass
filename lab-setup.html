실습 환경 셋업 (무료) — Windows 기준

학습 로드맵의 Phase 2부터 사용. 검증은 직접 코딩해야 늘기 때문에, Phase 2 시작 전에 환경부터 만든다. 결론: UVM은 EDA Playground(설치 0), 로컬 Verilog 연습은 Icarus+GTKWave, Python 강점 살리려면 cocotb.

0. 한눈 요약

도구 용도 설치 난이도 언제
EDA Playground SystemVerilog/UVM, 상용급 시뮬 온라인 없음(브라우저) Phase 3 UVM ⭐
Icarus Verilog (iverilog) Verilog/SV 시뮬 쉬움 Phase 2
GTKWave 파형(.vcd) 뷰어 쉬움 Phase 2~
cocotb Python 테스트벤치 보통(pip) Phase 2~3 선택
Verilator 초고속 시뮬(대형/회귀) 어려움(WSL 권장) 선택

1. EDA Playground (UVM의 정답, 설치 0)

브라우저만 있으면 된다. UVM은 무조건 이걸로 시작하세요(로컬에 UVM 깔기는 초보에게 지옥).

  1. https://edaplayground.com 접속 → 무료 회원가입(이메일).
  2. 좌측 패널: - Testbench + Design 두 파일 편집. - Languages & Libraries → SystemVerilog/Verilog, UVM 버전 선택(예: UVM 1.2). - Tools & Simulators → 무료로 쓸 수 있는 시뮬레이터(예: Aldec Riviera-PRO, Synopsys VCS) 선택. - Open EPWave after run 체크 → 실행 후 파형 자동.
  3. Run → 우측에 로그, 파형(EPWave) 표시.
  4. 작업물은 Save로 URL 생김 → 포트폴리오/공유에 사용.

장점: 설치·라이선스 0, 상용 시뮬과 거의 동일 경험. 단점: 대형 프로젝트엔 부적합(미니프로젝트엔 충분).

2. Icarus Verilog + GTKWave (로컬 Verilog 연습)

설치 (Windows)

  • 방법 A (권장, winget): powershell winget install IcarusVerilog.IcarusVerilog winget install GTKWave.GTKWave
  • 방법 B: bleyer.org/icarus 설치 파일(GTKWave 포함) 다운로드 → 설치 시 PATH 추가 체크.

동작 확인

iverilog -V

기본 사용 흐름

# 1) 컴파일 (디자인 + 테스트벤치)
iverilog -g2012 -o sim.out design.v tb.v
# 2) 실행 → .vcd 생성($dumpfile/$dumpvars가 tb에 있어야 함)
vvp sim.out
# 3) 파형 보기
gtkwave dump.vcd

-g2012 = SystemVerilog 2012 문법 일부 지원. iverilog는 UVM은 안 됨(UVM은 EDA Playground로).

3. cocotb (Python으로 테스트벤치 — 기계공학부 Python 강점)

HDL은 iverilog로 시뮬하고, 자극·체크는 Python으로 짠다. UVM 진입 전 "검증 사고"를 Python으로 익히기 좋다.

python -m pip install cocotb cocotb-bus
# 시뮬레이터로 icarus 사용
  • 디자인은 Verilog(design.v), 테스트는 Python(test_xxx.py).
  • Makefile 또는 cocotb-config 기반 실행. (cocotb 공식 quickstart 따라 1개 예제만 돌려보면 감 잡힘)
  • 장점: 파이썬 자료구조·랜덤·assert로 빠르게 자극/스코어보드 작성.

4. Verilator (선택 — 빠르지만 진입장벽)

대형/회귀 시뮬에 압도적으로 빠르나, Windows 네이티브는 까다로워 WSL2(Ubuntu) 권장.

# WSL Ubuntu
sudo apt update && sudo apt install verilator gtkwave

미니프로젝트 단계에선 불필요. 나중에 회귀 자동화할 때 고려.

5. 권장 셋업 순서 (체크리스트)

  • ☐ EDA Playground 가입 + UVM "hello world" 1회 Run (Phase 3 전)
  • ☐ winget으로 iverilog + GTKWave 설치, iverilog -V 확인
  • ☐ 빈 폴더에서 design.v+tb.v로 카운터 1개 시뮬 → GTKWave로 파형 확인 (= Phase 2 랩1)
  • ☐ (선택) cocotb 설치 + 공식 예제 1개 Run
  • ☐ Git 저장소 하나 만들어 실습물 버전관리 시작(= 나중에 포트폴리오)

막히면: 로컬 설치로 시간 빼앗기지 말고 EDA Playground로 먼저 진도를 빼세요. 환경은 거들 뿐, 핵심은 코드량.
