검증 엔지니어 취업 — 학습 로드맵

목표 직무: 디지털 검증(Design Verification) 엔지니어 학습자 배경: 기계공학부 (수학·물리 OK / 디지털·HDL·프로그래밍은 신규) 구성: ① 소자물리 1.5주(개념 이해) → ② 검증 10주(개념+핸즈온, 취업 수준) 원본 목표: 원본-학습목표.md

0. 큰 그림 (총 ~11.5주)

단계 기간 수준 핵심
Phase 0 · 소자물리 1.5주 (9일) 개념 이해 면접 교양 수준까지만, 깊게 파지 않음
Phase 1 · 검증 기초체력 1주 선수지식 디지털 논리 + 프로그래밍 갭 메우기
Phase 2 · HDL 2주 핸즈온 Verilog/SystemVerilog 직접 작성
Phase 3 · UVM 2.5주 핸즈온 검증 방법론의 심장
Phase 4 · 프로토콜 1.5주 개념+분석 APB/AXI/Cache Coherency
Phase 5 · 시뮬·SoC·DFT 2주 개념+실무 빌드/타이밍/부팅/전력/테스트

⚠️ 잠은 줄이지 말 것. 기술 학습은 수면 중 장기기억 고착이 핵심. 하루 딥워크 5~6h + 수면 7h가 "8h 갈아넣기"보다 시험·면접에서 강하다.

🎯 실제 취업 면접은 Phase 0~6을 모두 끝낸 뒤, Phase 6에서 준비해 본다. 각 Phase 중간의 자가점검 질문/체크포인트는 "그날 배운 걸 굳히는 인출 학습"이지 면접이 아니다. (소자물리는 검증 직무 비중이 작아 교양 수준까지만.)

Phase 0 · 소자물리 (1.5주 = 11일 / 하루 5h / 개념 이해)

YouTube 「기초반도체공학」 33강(9h 4m)을 개념 이해 수준으로. 우리 슬라이드(semiconductor-device-physics의 dp0~dp5-3)를 예습·복습 짝으로. 구성: D1~D8 신규 학습(33강 전부) + D9~D11 신규 0, 개념 굳히기(인출 복습).

🔎 오해 주의 — 실제 취업 면접은 여기서 보지 않습니다. 면접은 모든 Phase(0~6)를 끝낸 뒤 Phase 6의 통합 면접 준비를 거쳐 한 번 봅니다. Phase 0의 D9~D11과 일자별 자가점검 질문은 그날 배운 개념을 '인출(능동적 회상)'로 굳히는 학습 도구일 뿐, 면접 시점이 아닙니다. (소자물리는 검증 직무에선 비중이 작아 '교양 수준'까지만.)

📐 하루 5시간 쪼개는 법

학습일(D1~D8): - 🎬 2.5h — 신규 영상. 1.25배속, 수식 나오는 구간만 1배속, 필기 필수(밴드 그림은 직접 그리며). - ✍️ 1.5h — 그날 핵심 유도를 손으로 다시. 영상 안 보고 백지에 재현 + 간단 문제 1~2개. - 🔁 1h — 복습. 전날 내용 5분 회상(스페이싱) + 해당 슬라이드로 그날 내용 정리. 예습·복습에 슬라이드를 쓰면 되감기가 줄어 체감 30% 단축.

복습·인출일(D9~D11): 신규 영상 0. (※ 실제 면접 아님 — 개념을 인출로 굳히는 날) - 🗣️ 2.5h — 자기설명(인출). 슬라이드를 덮고 자가점검 질문/Q&A를 말로 설명(녹음해 빈틈 확인). - ✍️ 1.5h — 약점만 재유도 / 막히는 영상 구간만 핀포인트 재시청. - 🔁 1h — 큰 그림 1분 스토리 말하기(밴드→pn→다이오드→MS→MOS→MOSFET) + 녹음 듣고 셀프 피드백.

✅ 일자별 자가점검 질문 (인출 점검 — 말로 설명하기)

이 질문들은 그날 학습을 굳히는 회상(retrieval) 도구다. 실제 면접 대비가 아니라 "내가 이해했나" 확인용. 실전 면접 준비는 전 Phase 후 Phase 6에서.

  • D1: ① E=−dV/dx에서 전위가 평평하면 E는? ② 전도대/가전자대/밴드갭/페르미 준위 각각 뭔가? ③ 정공은 실제 입자인가? 전자와 부호·이동방향 차이는?
  • D2: ① pn 붙이면 왜 공핍층이 생기나(확산↔드리프트 평형)? ② built-in potential은 어디서 오고, 도핑 높이면? ③ 단측 접합에서 공핍층은 주로 어느 쪽으로 퍼지나?
  • D3: ① 순/역방향에서 전위장벽·공핍층 변화? ② 공핍 정전용량이 전압따라 변하는 이유? ③ Zener vs Avalanche 항복 차이?
  • D4: ① 다이오드 전류를 나르는 주역은 소수캐리어다 — 왜? ② 소수캐리어가 지수적으로 줄어드는 이유? ③ I=I₀(e^{V/V_T}−1) 각 부분의 의미?
  • D5: ① diffusion capacitance는 언제(순/역) 중요? ② Schottky vs Ohmic을 가르는 핵심 요인(일함수)? ③ 정류작용이 생기는 직관?
  • D6: ① MOS 축적/공핍/반전을 게이트 전압으로 설명? ② 문턱전압의 직관적 정의? ③ 이종접합은 왜 쓰나?
  • D7: ① 문턱전압을 정하는 항들(일함수차·산화막전하·도핑)? ② MOSFET이 왜 "스위치"인가(채널 형성)? ③ linear↔saturation을 가르는 pinch-off란?
  • D8: ① 포화에서 V_DS 올려도 I_D 거의 일정한 이유? ② 바디효과가 V_th에 주는 영향? ③ subthreshold swing이 뭐고 ~60mV/dec 한계의 의미? ④ 단채널효과·스케일링이 왜 중요?

🎯 D1 상세 가이드 (Foundations)

왜 D1이 제일 중요한가: 0장의 밴드·페르미·정공은 기계공학부 커리큘럼에 없던 완전히 새 언어다. 여기가 흔들리면 1~5장 전체가 무너진다. 이날만 영상 두 번 봐도 된다.

꼭 잡고 갈 4개념: 1. E = −dV/dx — 전기장은 "전위 언덕의 기울기(내리막 방향)". 기계과의 위치에너지/힘 관계와 동일. 전위 평평 → 전기장 0. 2. 에너지밴드 — 전자가 앉을 수 있는 "자리의 지도". 전도대(E_c, 자유전자)·가전자대(E_v, 묶인전자)·그 사이 못 들어가는 틈 밴드갭(E_g). 세로축 = 전자 에너지(위로 갈수록 불안정). 3. 페르미 준위(E_F) — "전자가 어디까지 차 있나"의 기준선. 0K 직관에서 출발해, 유한 온도에선 점유확률 50% 지점. 평형에서 수평. 4. 정공(hole) — 전자가 빠진 "빈자리". 부호 +q, 전기장 방향으로 이동(전자와 반대). 실제 입자가 아니라 빈자리의 이동.

기계과 강점 활용: E=−dV/dx, 가우스 법칙, (다음 장의) 확산은 열전달의 푸리에 법칙·플럭스와 1:1 대응. 수식 자체는 부담 없으니 물리적 그림에 집중.

D1 끝 자가테스트: 위 4개를 백지에 그림+한 줄로 설명 가능하면 통과. 안 되면 dp0 + #2 한 번 더.

Phase 0 최종 합격선: "밴드다이어그램으로 pn접합·MOS를 그려 설명하고, MOSFET이 왜 스위치인지 1분 안에 말한다." → 검증 직무 면접엔 이걸로 충분. 더 깊이(2D 정전기학·정밀 캐리어 통계 등)는 파지 말 것.

Phase 1 · 검증 기초체력 (1주) — 기계공학부 필수 갭 메우기

검증은 "이해"가 아니라 "코딩 기술"이라, 선수지식 없이는 UVM에서 무너진다.

  • 디지털 논리 (2~3일): 조합/순차 회로, 플립플롭, FSM, 셋업/홀드 직관
  • 우리 자료: 기본 ch0-2(디지털 회로 복습), ch0-3(검증이란)
  • 심화 예습: adv-ch0-2(타이밍·CDC)
  • 프로그래밍/OOP (2~3일): UVM이 객체지향이라 필수. Python을 이미 한다면 클래스/상속/팩토리 개념만 빠르게.
  • 실습 환경 셋업 (Phase 2 시작 전 완료) → 아래 실습 환경 참고
